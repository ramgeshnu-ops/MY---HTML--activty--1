## 🖼️ Adding Your Profile Photo

1. Take or find a good quality headshot photo.
2. Rename it to **`profile.jpg`**.
3. Place it inside the `images/` folder.
4. The website will automatically display it in the hero section.

> **Tip:** A square image (1:1 ratio) works best for the circular frame.
> If no photo is provided, a beautiful **"SG" initials avatar** is shown automatically.

### Deploy on GitHub Pages (Free Hosting)

1. Go to your repository → **Settings → Pages**
2. Source: **main branch → / (root)** → **Save**
3. Live at: `https://sreegeshnuram.github.io/sreegeshnuram-portfolio/`
